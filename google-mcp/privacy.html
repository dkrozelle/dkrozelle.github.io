google-mcp privacy policy

Last updated: October 24, 2026

google-mcp is a personal, single-user tool. The only person who uses it is its developer, Dan Rozelle, with his own Google accounts.

What data it accesses

With the account owner's consent, google-mcp uses Google APIs to read, draft, send and organize Gmail messages and to read and manage Google Calendar events. It only accesses this data when the account owner asks it to.

Where data goes

  • OAuth tokens are stored only in the macOS Keychain on the owner's computer.
  • Email and calendar data is processed on the owner's computer and shown to the owner's own AI assistant session. Attachments the owner chooses to download are saved to that computer.
  • No data is sold, shared with third parties, used for advertising, or sent to any server operated by google-mcp. There is no such server.

Google API Services User Data Policy

google-mcp's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
